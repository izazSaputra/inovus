# Font sources

- Open Sauce One Regular, Medium, Bold: https://github.com/marcologous/Open-Sauce-Fonts
  Licensed under SIL OFL 1.1; license included in `Open-Sauce-One-OFL.txt`.
- OffBit Dot: Power Type Foundry's personal-use download at https://www.dafont.com/offbit.font
  Used for this local design preview. The download is personal-use only, not OFL.
  Confirm an appropriate web license before publishing: https://power-type.com/offbit/
  The downloaded font is ignored by Git to avoid redistributing it. For a fresh checkout,
  supply an appropriately licensed `public/fonts/OffBit-Dot.ttf`; the display text falls
  back to monospace without the font.

Fonts are served locally so the preview does not need a third-party font request.
